# Iris Flower Classification - CodeAlpha Task 1

This repository contains my submission for **Task 1: Iris Flower Classification** during my Data Science Internship at CodeAlpha.

## Project Overview
The goal of this project is to train a machine learning model to classify iris flowers into three distinct species (*Setosa*, *Versicolor*, *Virginica*) based on their sepal and petal measurements.

## Dataset
The dataset utilized is the classic Iris dataset, containing 150 rows of flower measurements (Sepal Length, Sepal Width, Petal Length, and Petal Width).

## Tech Stack & Libraries
- **Language:** Python
- **Environment:** Google Colab
- **Libraries:** Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib
- **Algorithm:** Random Forest Classifier

## Evaluation Metrics
- **Model Accuracy:** 90.00%
- Fully evaluated using a Classification Report and Confusion Matrix visualization.
